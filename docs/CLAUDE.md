# GB Softwares — Web Design System

## Objetivo

Este repositório é um sistema de criação de templates front-end reutilizáveis para sites comerciais. O foco é criar interfaces com direção de arte real, evitando aparência genérica, de template ou de conteúdo gerado automaticamente.

## Stack obrigatória

- HTML5 semântico
- SCSS
- JavaScript Vanilla
- Bootstrap 5.3.x
- Bootstrap Icons
- Swiper

## Documentação obrigatória

Antes de implementar ou alterar um template, leia estes documentos na ordem:

1. `01-design-dna.md` — princípios visuais e regras anti-template.
2. `02-niche-art-direction.md` — direções visuais por nicho.
3. `03-frontend-ui-system.md` — arquitetura técnica e padrões de implementação.
4. `04-master-prompt.md` — instruções completas de direção e execução.

## Regra principal

A stack pode ser reutilizada. A aparência não deve ser reutilizada de forma automática.

O conteúdo, o nicho e a direção de arte devem determinar a composição, a tipografia, a densidade, o uso de imagens, os componentes e o ritmo da página.

## Prioridade de decisão

Quando houver conflito entre um padrão visual genérico e uma regra de direção de arte, siga a direção de arte.

Quando houver conflito entre adicionar elementos e manter clareza, prefira clareza.

Quando o conteúdo não justificar uma seção ou componente, não crie a seção apenas para preencher a página.
